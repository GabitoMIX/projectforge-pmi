# Página de presentación - ProjectForge PMI

Esta rama está pensada para publicarse con GitHub Pages.

## Qué contiene

- `index.html`: página principal.
- `styles.css`: estilos visuales.
- `script.js`: menú responsive y botones de copiar.
- `assets/projectforge-logo.svg`: logo simple del proyecto.

## Qué debes cambiar

Busca y reemplaza:

```txt
https://github.com/TU_USUARIO/projectforge-pmi
```

por el enlace real de tu repositorio.

También puedes cambiar:

```txt
https://projectforge.argeworks.com
```

por el dominio real de la demo.

## GitHub Pages

En GitHub:

1. Settings.
2. Pages.
3. Source: Deploy from a branch.
4. Branch: `gh-pages`.
5. Folder: `/root`.
6. Save.

## Dominio personalizado

Si vas a usar un subdominio, configura el dominio desde Settings > Pages > Custom domain.
GitHub creará el archivo `CNAME` automáticamente.
